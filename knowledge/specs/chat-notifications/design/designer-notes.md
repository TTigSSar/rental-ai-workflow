# Designer notes (from nt-app.jsx `NNotes`, Claude Design export 2026-11-07)

- **Frame 3 · recommendation: Option B** (approved by Tigran). The soft prompt explains why the browser is about to ask, and the browser dialog opens only after "Turn on". Browsers can show a quieter prompt or block repeat requests once a site has been dismissed.
- **Soft prompt rules.** Shown once per device after the first sent message, as the last item in the thread, so it scrolls with the messages and never overlaps the composer or the keyboard. "Not now" and "Turn on" both remove it for good. After "Turn on", the browser dialog opens; the thread itself does not change.
- **Settings.** Notifications is a row in the settings card, like Language. Tapping it opens the same container Language uses (bottom sheet on mobile, 560 px dialog on desktop) with one card holding the two rows. Changes save immediately, so there is no Save button; close or swipe down to leave. Row A is a switch that saves on change; a short "Saved" or failure line appears under its hint (save failed → switch goes back). Row B has no off switch, because the page can't take back browser permission; "On" is a status pill with a pointer to browser settings.
- **Contrast.** Switch on: #C24600 track with white knob. Off: #6F6E7D outline and knob on white (5.0:1). "On" pill #0D7D56 on #EDF9F1. Warning note text #1A1B26 on #FFF4D6 with a #8A5C00 icon (5.3:1). Save failure text #CC2D25.
- **Unsubscribe page.** Opening the link changes nothing; the button does the work. Results replace the card body with a tinted icon, a one-line heading (announced as status) and one link. Error line sits above the button and the button stays enabled.
- **Email.** Single 600 px column, no message text. Heading carries sender first name and toy title; the toy row repeats the title next to a 64 px thumbnail. Button is a link styled #C24600 with white text, 48 px high, full width under 600 px. Footer links are underlined muted text.

Board frames: Settings mobile/desktop + RU length; Row B states strip; Row A save feedback (ok / failed / keyboard focus); Chat Option A, Option B, B with keyboard open, B after "Turn on"; Unsubscribe confirm/loading/failed/done/invalid/already + desktop confirm; Email 600 px, 2-line toy title, RU, HY, phone width.
